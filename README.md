# Dr. James Jack Neurology Portfolio

A responsive, static multi-page neurology portfolio and information website.

## Pages

- `index.html` - Home
- `about.html` - Profile and background information
- `specialties.html` - General neurology education topics
- `services.html` - General visit information and FAQs
- `gallery.html` - Healthcare and profile artwork gallery
- `contact.html` - Front-end-only contact form demonstration
- `appointment.html` - Front-end-only appointment inquiry demonstration

## Run locally

Open `index.html` in a browser, or serve this folder through a local web server such as XAMPP.

Styles, scripts, and local image assets are in `assets/`. The forms do not transmit or store submissions. Profile, credential, contact, and hospital-affiliation details should be independently verified before publication. Image usage notes are in `assets/images/README.md`.
